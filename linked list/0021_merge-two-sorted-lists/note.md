# LeetCode 0021 合并两个有序链表

**题目链接**：https://leetcode.cn/problems/merge-two-sorted-lists/

## 题目描述

将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

### 示例

示例1：
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]

示例2：
输入：l1 = [], l2 = []
输出：[]

示例3：
输入：l1 = [], l2 = [0]
输出：[0]

### 约束条件

- 两个链表的节点数目范围是 [0, 50]
- -100 <= Node.val <= 100
- l1 和 l2 均按 非递减顺序 排列

## 解题思路

采用**哑节点（哨兵节点）+双指针迭代**方案。

1. 创建虚拟哑节点`dummy`，用来统一处理链表头部，避免单独判断头节点；
2. 使用cur指针作为工作指针，用来拼接新链表；
3. 同时遍历list1、list2，每次选取值更小的节点接到cur后面；
4. 对应链表指针后移，cur指针同步向后走；
5. 当其中一条链表遍历完毕，直接把另一条链表剩余节点全部接到尾部；
6. 返回`dummy.next`，也就是合并完成链表的真实头节点。

> 特点：原地复用原有节点，不新建节点。

## 复杂度分析

- 时间复杂度：$O(n+m)$，n、m分别为两条链表节点数量，每个节点仅访问一次
- 空间复杂度：$O(1)$，仅使用常数额外空间（哑节点、指针变量）

## 易错点

1. 边界判断：链表为空的情况（一条为空、两条都为空）
2. while循环结束之后，**必须把剩下未遍历完的链表接上**
3. 不要忘记移动cur指针，否则会在同一个节点不断覆盖

这道题是单向链表经典题，核心技巧是**哑节点dummy**，用来消除对头节点的特殊判断。双指针依次比较两个链表节点，取较小节点拼接；当其中一个链表遍历结束，直接拼接剩下链表。不需要额外开辟节点空间，原地修改next指针完成合并。
