# LeetCode 算法题记录

本仓库用于记录LeetCode算法题，这里按题目类型整理刷题过程中保存的题目描述、解题笔记和代码，本仓库处于持续更新中。

## 目录结构

按题目类型建立分类目录，每道题单独放在一个子目录中：

```text
LeetCode/
├── README.md
└── linked list/
    └── 题号_题目英文名/
        ├── note.md
        └── main.cpp
```

例如：`linked list/0021_merge-two-sorted-lists/`。

## 文件说明

- `note.md`：记录题目链接、题目描述、示例与约束，并整理解题思路、复杂度和易错点。
- `main.cpp`：保存对应的 C++ 解法。可按需要附上本地运行用的 `main` 函数和测试数据。

## 新增题目

1. 在对应类型目录下创建题目目录，建议命名为 `题号_题目英文名`，例如 `0021_merge-two-sorted-lists`。
2. 在目录中创建 `note.md` 和代码文件；代码文件按语言命名，例如 `main.cpp`。
3. 笔记中的题目链接和题号应与代码对应；解题记录尽量写清关键思路、复杂度与边界情况。
4. 如果题目属于新的类型，先创建相应的分类目录。

## 本地运行 C++ 代码

在题目目录中使用支持 C++ 的编译器编译，例如：

```bash
g++ -std=c++17 main.cpp -o main
```

Windows 下可运行生成的 `main.exe`；其他系统运行 `./main`。如果代码包含本地测试用的 `main` 函数，可直接运行；提交到 LeetCode 时按平台要求保留题目要求的解法部分。
